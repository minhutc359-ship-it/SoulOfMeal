# Soul of Meal — Hành Trình Vị Linh

Anime food-fantasy browser game with Adventure, tactical card battles and an Auto Chess tournament. The three modes share character identity while keeping their rule systems and balance independent.

## Play locally

```sh
cd Soul_of_Meal_COMPLETE_SPEC_v3/Soul_of_Meal_COMPLETE_SPEC_v3
npm run dev
```

Open http://127.0.0.1:4173/client/. No dependency install is required.

Run `npm test`, `npm run build`, `npm run check` and `python -m unittest discover -s tests -v` from the same directory.
