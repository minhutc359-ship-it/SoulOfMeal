# D-014 — Asset Licensing and Provenance

- **Status:** APPROVED (policy baseline; per-asset legal sign-off remains required)
- **Context:** References include third-party games; release assets need traceable ownership and usage rights.
- **Decision:** Release only original or appropriately licensed assets. Record source, creator/owner, license and provenance for every shipped asset. Do not copy protected reference-game assets.
