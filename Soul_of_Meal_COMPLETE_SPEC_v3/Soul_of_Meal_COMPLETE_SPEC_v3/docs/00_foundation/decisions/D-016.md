# D-016 — Touch Targets and Safe Areas

- **Status:** APPROVED (accessibility/layout baseline; device validation remains required)
- **Context:** Touch controls must remain reachable across mobile devices and system insets.
- **Decision:** Use a minimum 44 dp touch target and honor operating-system safe-area insets.
- **Approved by:** Project Owner (authorized by chat instruction; display name not provided)
- **Approved on:** 2026-11-10
- **Implications:** Compact controls may use larger hit areas than their visible icon; text and controls must not be obscured by insets.
- **Rollback:** Supersede only if usability/accessibility evidence supports a change and platform guidance is reviewed.
- **Test fixtures:** UI layout checks at the documented portrait/landscape logical sizes plus real-device safe-area and touch testing.
