# D-006 — Adventure Damage Formula

- **Status:** APPROVED (prototype rules baseline; balance is not release-final)
- **Context:** Combat needs deterministic integer damage independent of rendering.
- **Decision:** Calculate pre-critical damage as `max(1, floor(ATK * coefficient * 100 / (100 + DEF)))`, with the coefficient represented as configured fixed-point data.
- **Approved by:** Project Owner (authorized by chat instruction; display name not provided)
- **Approved on:** 2026-11-10
- **Balance/version implications:** Preserve the formula in rules versioning; coefficient and stat balance remain tunable data and require playtesting.
- **Rollback:** Change formula only with a new rules version and replay/fixture migration plan.
- **Test fixtures:** 320 ATK × 1.5 coefficient vs 100 DEF resolves to 240; existing Adventure tests exercise this case.
