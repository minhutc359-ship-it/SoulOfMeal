# D-003 — Save and Persistence

- **Status:** APPROVED (design/prototype baseline; recovery tests remain required)
- **Context:** P0 should work locally and recover progression without requiring online services.
- **Decision:** Use local-first saves with an explicit schema version and migration path. Cloud synchronization is optional and out of P0 scope.
- **Approved by:** Project Owner (authorized by chat instruction; display name not provided)
- **Approved on:** 2026-11-10
- **Implications:** Claims and progression must be idempotent; local storage is not a trusted authority for future competitive play.
- **Rollback:** Supersede before introducing cloud sync or changing the persistence authority model.
- **Test fixtures:** Save/reload, migration, corruption recovery and duplicate reward-claim cases are release gates; implementation is not present yet.
