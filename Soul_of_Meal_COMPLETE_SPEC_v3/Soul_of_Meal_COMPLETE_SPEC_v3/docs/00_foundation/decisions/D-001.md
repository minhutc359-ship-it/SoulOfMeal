# D-001 — Renderer Baseline

- **Status:** APPROVED (design/prototype baseline; engine benchmark remains a production gate)
- **Context:** The project needs a 2D/2.5D renderer, atlas and texture management, and broad browser compatibility.
- **Decision:** Use WebGL as the required rendering baseline. WebGPU may be used as an optional enhancement, never as a requirement. Keep content and rules engine-neutral; select a named engine only after the documented three-device benchmark.
- **Approved by:** Project Owner (authorized by chat instruction; display name not provided)
- **Approved on:** 2026-11-10
- **Implications:** No production engine claim until the benchmark compares representative candidates and records results.
- **Rollback:** Supersede this ADR after benchmark evidence or a platform-scope change.
- **Test fixtures:** Golden Sample scene benchmark on three target devices; record FPS p50/p95, memory, load time and compatibility.
