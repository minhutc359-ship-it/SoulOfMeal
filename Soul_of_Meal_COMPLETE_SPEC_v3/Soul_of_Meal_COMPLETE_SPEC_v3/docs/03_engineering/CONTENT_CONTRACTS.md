# Content Contract Index

Shared IDs: `chr_<...>`, `abl_<...>`, `card_<...>`, `vfx_<...>`, `sfx_<...>`, `map_<...>`, `quest_<...>`. ASCII snake_case in JSON and filenames, human-facing Vietnamese in `display_name` localization fields. No naked reference string to an image file inside game rule expression.

- Character identity → `examples/characters/<character_id>/identity.json`.
- Sprite job → `examples/characters/chr_bunbo_holinh/sprite_job.json`.
- Ability coefficient fixture → `examples/adventure/bunbo_ability.json`.
- Card catalog → `examples/cards/cards.catalog.json`.
- Trap cards may define `trigger: {when, condition}`; the current prototype supports `spell_cast` + `condition.card_type: fast_spell`, or `attack_declared` + `condition.min_attackers`, for `conditional_counter` examples only.
- Deck fixture → `examples/cards/starter_deck.json`; exactly 36 cards, ≤2 duplicates per card ID.
- Chess shop tiers → `examples/auto_chess/shop_odds.json`; each level odds sum to 100.
- Chess unit roster → `examples/auto_chess/units.json`.
- Source examples v2 → `archive/v2_production_spec/examples/*`.
- Sprite atlas generated by skill script `build_atlas.py` (uniform cell, per-page JSON), validated by `validate_sprite.py`.

**Versioning:** every catalog carries `catalog_version`, matches replay and save snapshots. Pending balance values are marked `v3-proposed`. Before shipping, export compiled catalogs from one authoritative data build; never copy `example` fixture into public production blindly.
